# Asset audit

The audit distinguishes assets used by the migrated site from original material retained for reproducible visual comparisons. The original fixture is test input, never part of `public/` or `dist/`.

| Original asset                                             | Classification                                                | Migration                                                                    |
| ---------------------------------------------------------- | ------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `Assets/img/pic/profile.png`                               | Used in Home, About, and social metadata                      | `src/assets/profile.png`; responsive WebP images generated by Astro          |
| `Assets/img/project/staycation.png`, `melinjo.png`         | Used by Portfolio and project dialogs                         | `src/assets/`; responsive WebP generated by Astro                            |
| `Assets/img/favicon/letter-a.png`                          | Used                                                          | `public/favicon/letter-a.png`                                                |
| `Assets/img/CV/CV_Frontend-Arief_Setiawan.pdf`             | Used                                                          | `public/cv/`; existing tab-opening behavior retained                         |
| `Assets/css/font-awesome.css`                              | Used third-party stylesheet                                   | `public/font-awesome.css`; font URLs adjusted for its new location           |
| `Assets/webfonts/*` (15 files)                             | Referenced font faces and fallback formats                    | `public/webfonts/`; retained intact for parity                               |
| `Assets/css/style.css`                                     | Legacy source of the design                                   | Migrated to `src/styles/global.css`; original retained in test fixture       |
| `Assets/js/script.js`                                      | Legacy runtime                                                | Replaced by typed modules; original retained only as comparison input        |
| `Assets/img/pic/about.png`, `img_profile.JPG`, `meta .png` | Unused by active original markup                              | Not copied into production assets; retained in original fixture              |
| `Assets/dummys/profile-img.png`, `about-img.png`, `cv.pdf` | Dummy/unused                                                  | Not copied into production assets; retained in original fixture              |
| `Assets/dummys/portfolio/*.jpg`                            | Dummy; one placeholder in original modal and a commented card | Real project templates replace modal placeholder; no dummy production copies |

The duplicate legacy root HTML and `Assets/` were removed after all nine visual checks passed. Their exact copies in `tests/visual/legacy` remain the comparison source of truth. Do not edit those copies to accommodate implementation differences.

Google-hosted Poppins is intentionally retained. Hero images are eager/high priority; nonhero images are lazy. Source dimensions and responsive candidates are explicit. Optimization must remain visually acceptable in comparison tests; compression savings do not override design parity.
